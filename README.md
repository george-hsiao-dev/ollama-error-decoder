# Ollama Error Decoder

Paste an Ollama error log and get likely causes plus a short recovery checklist for common memory, context, model, network, port, disk, permission, and driver failures.

- Runs entirely in the browser
- Does not upload or store logs
- Uses transparent pattern matching
- Includes a generic diagnostic path when no exact pattern matches
